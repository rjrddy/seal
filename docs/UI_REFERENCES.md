# A proof document

Original red/ivory archival document: oversized record title, typographic oval seal, ruled log register, separate trust-anchor fields, editable proof, challenge controls and stamped verdict. This is a small buildless viewer, not a reused dashboard or component template. All graphics and CSS are original; no external fonts or images are loaded.

Primary outside source: [How Certificate Transparency works](https://certificate.transparency.dev/howctworks/), consulted for the separation of logs, monitors, signed heads and proof claims. [RFC 9162](https://www.rfc-editor.org/rfc/rfc9162.html) informs the distinction between membership and prefix consistency. No code, artwork, company usage claim or protocol branding was copied.

Actual responsive screenshots, corrupted-proof checks, Rust/WebCrypto agreement, trust-anchor persistence, downloads, network recovery and keyboard focus are retained under docs/results/browser/. These checks are not a complete accessibility or cryptographic audit.
