# Combine a canonical hash chain with RFC-shaped Merkle commitments

Accepted. A hash chain makes sequence/link audit straightforward; a Merkle tree gives compact membership and prefix-consistency evidence. Domain-separated hashes and length-delimited binary signing messages avoid ambiguous concatenation. Canonical JSONL rejects representational file edits too. The format is original and is not Certificate Transparency wire compatible. Full audit, membership and consistency prove different claims.
