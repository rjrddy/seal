# Seal provenance

The approved salvage audit selected no direct source transfer for Seal. Its Rust log/CLI, canonical encoding, storage writer fence, Merkle algorithms, signed checkpoint/bundle format, browser checker, tests, benchmarks and original viewer were written here.

Cryptographic primitives come from locked public sha2 and ed25519-dalek dependencies; the tree/proof structure follows the cited RFC. No old project source, employer interface or private dataset was used. Every fixture is synthetic. The deterministic viewer/benchmark keys are explicitly public demo identities; CLI keygen uses OS randomness for caller-managed keys.

No Tally source was modified. A separate integration proposal describes a future bridge only, gated on acceptance and explicit approval. No old directory or remote was removed and no hosting account was created.
