03 / HOW TO READ THE RESULT

Included is not the same as consistent.

Inclusion binds an entry to a signed tree root. Consistency proves a later tree extends an earlier root. The hash chain catches broken sequence links; a retained signed head exposes removal of the tail.

The primitives are standard. The scope is explicit.
